# 전체 시스템 통합

> ⚠️ 이전 버전(Jetson 단독 멀티스레드 메인 루프 + GStreamer/OpenCV HUD)은 폐기됨. 확정 구조는 **Jetson(오디오 전담, ROS 미사용) / 노트북(카메라·LiDAR·BEV UI, ROS2)** 분리다. 세부 배경은 `00_Overview/현재_상태_요약.md` "시스템 아키텍처", "통신 미들웨어 및 물리 연결" 절 참고. 아래 코드는 실제 구현이 아니라 설계 골격이며, 실제 구현 시 갱신 필요.

## 전체 구조

```
[Jetson]                          [노트북, ROS2]
realtime_classify.py (수정 예정)    bridge_node ── /audio/detection ──┐
  - ReSpeaker 캡처                                                    │
  - AST 추론 (5클래스)              camera_node ×4 ── /camera_*/image_raw
  - DoA 계산                        lidar_node ── /velodyne_points     │
  - 소켓/JSON 송신 ──이더넷──▶                                        │
                                   matching_node ◀──────────────────┘
                                     (오디오 트리거 시에만 YOLO+LiDAR 매칭 실행)
                                     → /vehicle/candidates
                                   ui_node (BEV 앱)
                                     ← /vehicle/candidates, /camera/*, /audio/detection
```

**원칙**: 카메라·LiDAR 노드는 부팅 시 한 번 실행 후 상시 퍼블리시. 오디오 감지는 노드 실행/종료가 아니라 `matching_node`의 처리 시작 조건으로만 작동한다 (LiDAR는 기계식이라 스핀업 지연이 크고, 카메라 캡처 자체는 가벼워서 상시 유지가 유리함).

## Jetson 쪽 (ROS 미사용)

기존 `03_Audio_Classification/code/realtime_classify.py`는 콘솔 출력만 하므로, 분류 결과를 노트북으로 보내는 송신 로직 추가가 필요하다.

```python
# 개념 골격 — 실제 구현 시 realtime_classify.py에 통합
import json
import socket
import time

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)  # 또는 zmq.PUB
LAPTOP_ADDR = ("192.168.50.1", 5555)  # 이더넷 직결 고정 IP (예시)

def send_detection(t, class_name, conf, theta, sigma):
    payload = json.dumps({
        "t": t, "class": class_name, "conf": conf,
        "theta": theta, "sigma": sigma,
    }).encode()
    sock.sendto(payload, LAPTOP_ADDR)
```

- 젯슨은 고정 IP + 노트북과 시계 동기화(chrony/NTP) 필요 — `06_Display_Integration/ui_state_spec.md` §7의 "점별 시각 매칭" 정확도가 여기 좌우된다.
- 전송 주기는 인터페이스 스펙(초당 4회)에 맞춰야 함 — 현재 코드 기본값(2초당 1회)과 불일치, 정리 필요.

## 노트북 쪽 (ROS2)

### 브릿지 노드

```python
# bridge_node.py — 젯슨 소켓 JSON을 ROS2 토픽으로 republish
import json
import socket
import rclpy
from rclpy.node import Node
from std_msgs.msg import String  # 프로토타입 단계, 추후 커스텀 msg로 교체 권장

class AudioBridge(Node):
    def __init__(self):
        super().__init__('audio_bridge')
        self.pub = self.create_publisher(String, '/audio/detection', 10)
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.sock.bind(("0.0.0.0", 5555))
        self.timer = self.create_timer(0.01, self._poll)

    def _poll(self):
        self.sock.settimeout(0.0)
        try:
            data, _ = self.sock.recvfrom(4096)
            msg = String()
            msg.data = data.decode()
            self.pub.publish(msg)
        except BlockingIOError:
            pass

def main():
    rclpy.init()
    rclpy.spin(AudioBridge())
```

- 소켓 끊김/재연결 처리는 실제 구현 시 추가 필요 (차량 내 무선 연결은 끊김이 잦으나, 이더넷 직결이면 상대적으로 안정적).
- 정식 구현에서는 `std_msgs/String`(JSON) 대신 커스텀 메시지(`AudioDetection.msg`: t/class_name/conf/theta/sigma)로 교체 권장.

### 매칭 노드 (트리거 기반 처리, 세부 구현 예정)

```python
# matching_node.py — 개념 골격
class VehicleMatcher(Node):
    def __init__(self):
        super().__init__('vehicle_matcher')
        self.create_subscription(String, '/audio/detection', self._on_audio, 10)
        self.pub = self.create_publisher(String, '/vehicle/candidates', 10)
        # 최신 LiDAR/카메라 프레임은 별도 구독으로 항상 최신값 유지

    def _on_audio(self, msg):
        detection = json.loads(msg.data)
        if detection['class'] in ('none', 'children_playing', 'engine_idling'):
            return  # 비경보 클래스는 매칭 생략
        # 1. LiDAR 클러스터 추출 (방위각+거리)
        # 2. 해당 방향 카메라에서 YOLO 검출
        # 3. theta(±sigma)와 매칭되는 후보 선정 후 발행
```

### 토픽 구조 요약

| 토픽 | 발행 조건 | 내용 |
|---|---|---|
| `/audio/detection` | 상시 | 젯슨 분류·DoA 결과 |
| `/camera_{dir}/image_raw` | 상시 | 카메라 4대 영상 |
| `/velodyne_points` | 상시 | LiDAR 포인트클라우드 |
| `/vehicle/candidates` | 오디오 트리거 시에만 계산 | LiDAR+카메라+오디오 매칭 결과 |
| `/ui/state` | `/vehicle/candidates` 갱신 시 | BEV UI 상태(IDLE/표시/주의/경고) |

## ROS2 launch 구성 (예시)

```python
# owlmirror_bringup.launch.py — 개념 골격
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(package='owlmirror', executable='audio_bridge', name='audio_bridge'),
        Node(package='velodyne_pointcloud', executable='velodyne_convert_node', name='lidar'),
        Node(package='usb_cam', executable='usb_cam_node_exe', name='camera_front',
             parameters=[{'video_device': '/dev/video0'}]),
        # camera_rear / camera_left / camera_right 동일 패턴으로 추가
        Node(package='owlmirror', executable='vehicle_matcher', name='vehicle_matcher'),
        Node(package='owlmirror', executable='ui_node', name='ui_node'),
    ])
```
