# 카메라 4대 + LiDAR 연결 및 노트북 디스플레이

> ⚠️ 이전 버전(Intel RealSense Depth 카메라 1대 기준)은 폐기됨. 확정 하드웨어는 **일반 카메라 4대(전/후/좌/우 90°) + LiDAR VLP-16**이며, 거리 측정은 LiDAR가 전담한다. 배경: `00_Overview/현재_상태_요약.md` "거리 추정 방식 전환" 참고.

## 역할

오디오 단독 방향 추정의 오차(±10~20°)를 보완하고, "어느 차량이 그 소리를 냈는지" 특정하기 위한 센서 조합.

| 센서 | 담당 | 역할 |
|---|---|---|
| 카메라 4대 | 노트북 | 영상 확인(운전자 보조 화면) + YOLO 기반 긴급차량 경광등 점멸 검출 |
| LiDAR VLP-16 | 노트북 | 후보 차량까지의 거리 측정 (±2%) — 오디오/카메라로는 거리를 추정하지 않음 |

카메라는 "사람이 보는 장면", LiDAR는 "거리"를 담당하도록 역할을 분리했다.

## 하드웨어 구성

| 항목 | 사양 |
|---|---|
| 카메라 | 4대, 차량 전/후/좌/우 90° 간격 배치, 루프랙 프레임에 LiDAR와 함께 고정 |
| LiDAR | Velodyne VLP-16, 루프랙 프레임 중앙 최상단 고정 (차체에 가리면 하단 빔이 소실되므로 위치 주의) |
| 사각지대 | LiDAR 반경 약 6m 이내는 물리적 사각지대 — 근접 사각지대는 소리 + 예측으로 보완 |
| 센서 연결/동기화 | 연구실(멘토 측) 담당, 우리 팀은 인식·화면 로직 담당 |

## 노트북 측 ROS2 구성 (설계)

카메라·LiDAR는 **부팅 시 한 번 실행 후 상시 퍼블리시**한다. 오디오 감지로 트리거되는 것은 센서 노드 자체가 아니라, 그 위에서 도는 검출·매칭 연산이다 (LiDAR는 기계식이라 켰다 껐다 하면 스핀업 지연이 커서 상시 구동 필요).

```
LiDAR   : velodyne_driver / velodyne_pointcloud 패키지 → /velodyne_points (PointCloud2, 상시)
카메라  : usb_cam 또는 v4l2_camera 노드 4개 → /camera_{front,rear,left,right}/image_raw (상시)
오디오  : Jetson → (소켓/JSON, ROS 미사용) → 노트북 브릿지 노드 → /audio/detection (상시)
매칭    : /audio/detection 콜백에서 타겟 클래스+신뢰도 임계값 이상일 때만
          → YOLO 경광등 검출 실행 + LiDAR 클러스터링·거리 매칭 실행
          → /vehicle/candidates 발행
UI      : /vehicle/candidates, /camera/*, /audio/detection 구독 → BEV 지도 갱신
```

상세 통신 설계(브릿지 노드, 이더넷 직결, 시계 동기화 등)는 `00_Overview/현재_상태_요약.md` "통신 미들웨어 및 물리 연결" 절, 전체 노드 구조는 `07_System_Integration/전체_시스템_통합.md` 참고.

## 방향 → 거리 매칭 로직 (설계, 세부 구현 예정)

거리는 더 이상 오디오나 카메라 단독으로 추정하지 않는다. **LiDAR가 이미 측정한 차량 후보 중 소리 방향과 맞는 차량을 골라내는 방식**이다.

```
1. LiDAR 포인트클라우드에서 후보 클러스터 추출 (각 클러스터 = 방위각 + 거리)
2. 해당 방향 카메라 프레임에서 YOLO로 차량/경광등 후보 bbox 추출
3. 오디오 theta(±sigma) 범위 안에 있는 LiDAR 클러스터·카메라 bbox를 매칭
4. 매칭된 후보의 LiDAR 거리값을 최종 거리로 채택
```

시각 동기화 원칙(프레임이 아니라 점별 시각 사용, LiDAR 100ms 스캔당 오차)은 `06_Display_Integration/ui_state_spec.md` §7 참고.

## 경광등 점멸 검출 (YOLO, M4 단계)

- 평상시 경로: 밝기 변화 기반 규칙 검출 (학습 없이 ~0.5초)
- 야간/악천후로 경광등이 안 보이는 경우: 소리 방향 변화 + 차량 움직임 대조로 대체
- 어느 카메라(4대 중)에서 YOLO를 상시 돌릴지, 오디오 트리거 시에만 돌릴지는 노트북 연산 부하를 보고 결정 필요 (내일 회의 안건)

## 노트북 디스플레이
