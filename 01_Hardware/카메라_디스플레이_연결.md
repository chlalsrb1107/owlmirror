# Depth 카메라 및 디스플레이 연결

## Depth 카메라 역할

오디오 단독 TDoA/빔포밍의 차량 환경 오차(10~25°)를 보완하는 **주 추적 센서**.

| 기능 | 설명 |
|---|---|
| 차량 탐지 | YOLOv8 (COCO pretrained) — car, motorcycle, bus, truck 클래스 |
| 거리 측정 | Depth 프레임으로 탐지된 차량까지 거리 측정 |
| 접근 속도 추정 | 연속 프레임 간 거리 변화 → 접근 속도 |
| 방향 확인 | 오디오 DoA 초기 단서 → 카메라 해당 영역 집중 탐지 |

## 차량 탐지 + 거리 측정 파이프라인

```python
import pyrealsense2 as rs
import numpy as np
import cv2
# pip3 install ultralytics
from ultralytics import YOLO

model = YOLO("yolov8n.pt")  # COCO pretrained, 추론 시 TRT 변환 권장
VEHICLE_CLASSES = {2: 'car', 3: 'motorcycle', 5: 'bus', 7: 'truck'}

class DepthVehicleTracker:
    def __init__(self):
        self.pipeline = rs.pipeline()
        cfg = rs.config()
        cfg.enable_stream(rs.stream.color, 640, 480, rs.format.bgr8, 30)
        cfg.enable_stream(rs.stream.depth, 640, 480, rs.format.z16, 30)
        self.profile = self.pipeline.start(cfg)
        self.align = rs.align(rs.stream.color)

        # 거리 이력 (접근 속도 계산용)
        self.prev_distances = {}

    def get_frames(self):
        frames = self.pipeline.wait_for_frames()
        aligned = self.align.process(frames)
        color_frame = aligned.get_color_frame()
        depth_frame = aligned.get_depth_frame()
        color = np.asanyarray(color_frame.get_data())
        depth = np.asanyarray(depth_frame.get_data())
        return color, depth

    def detect_and_measure(self, color, depth, focus_angle=None):
        """
        focus_angle: 오디오 DoA가 제공한 집중 방향 (None이면 전체 탐지)
        """
        results = model(color, verbose=False)[0]
        detections = []

        for box in results.boxes:
            cls = int(box.cls[0])
            if cls not in VEHICLE_CLASSES:
                continue

            x1, y1, x2, y2 = map(int, box.xyxy[0])
            cx, cy = (x1 + x2) // 2, (y1 + y2) // 2

            # 오디오 DoA 방향으로 탐지 영역 필터링 (선택)
            if focus_angle is not None:
                frame_angle = (cx / color.shape[1] - 0.5) * 90  # ±45° 매핑
                if abs(frame_angle - (focus_angle % 90 - 45)) > 30:
                    continue

            # 중심점 depth 측정 (미터)
            dist_m = depth[cy, cx] * 0.001
            if dist_m == 0:
                dist_m = None

            detections.append({
                'class': VEHICLE_CLASSES[cls],
                'bbox': (x1, y1, x2, y2),
                'distance_m': dist_m,
                'confidence': float(box.conf[0])
            })

        return detections

    def estimate_approach_speed(self, det_id: str, dist_m: float,
                                 dt: float = 0.033) -> float:
        """연속 프레임 간 거리 변화로 접근 속도 추정 (m/s)"""
        if det_id not in self.prev_distances or dist_m is None:
            self.prev_distances[det_id] = dist_m
            return 0.0
        speed = (self.prev_distances[det_id] - dist_m) / dt
        self.prev_distances[det_id] = dist_m
        return speed  # 양수 = 접근, 음수 = 멀어짐

    def stop(self):
        self.pipeline.stop()
```

## 위험도 레벨 산출

```python
def calculate_threat_level(audio_label: str, dist_m: float,
                            approach_speed_ms: float) -> str:
    """
    Returns: 'CRITICAL' / 'WARNING' / 'CAUTION' / 'CLEAR'
    """
    if audio_label == 'background' or dist_m is None:
        return 'CLEAR'

    # 긴급차량은 기본 CAUTION 이상
    base = 1 if audio_label == 'emergency_siren' else 0

    score = base
    if dist_m < 10:
        score += 2
    elif dist_m < 20:
        score += 1

    if approach_speed_ms > 10:   # 36 km/h 이상으로 접근
        score += 2
    elif approach_speed_ms > 5:
        score += 1

    if score >= 4:
        return 'CRITICAL'
    elif score >= 2:
        return 'WARNING'
    elif score >= 1:
        return 'CAUTION'
    return 'CLEAR'
```

## Depth 카메라 환경별 한계

| 환경 | 영향 |
|---|---|
| 직사광선 (야외) | IR 기반 depth 품질 저하 |
| 비/우천 | depth 오차 증가 |
| 야간 | RGB 탐지 저하, depth는 상대적으로 유지 |
| 20m 이상 거리 | depth 신뢰도 급격히 감소 |

> 20m 이상 원거리는 오디오 감지 → 카메라 방향 유도 → 차량 접근 후 depth 측정 전환 방식으로 대응.
