# 빔포밍 알고리즘

## 빔포밍 vs TDoA 비교

| 방법 | 장점 | 단점 | 적합 용도 |
|---|---|---|---|
| GCC-PHAT TDoA | 계산 빠름, 구현 간단 | 반향에 약함 | 실시간 초기 추정 |
| SRP-PHAT 빔포밍 | 반향에 강함, 정확도 높음 | 계산량 많음 | 정밀 DoA 확인 |
| MUSIC | 다중 음원 분리 가능 | 공분산 행렬 필요 | 다중 차량 상황 |

**전략**: GCC-PHAT으로 빠른 초기 추정 → SRP-PHAT으로 정밀화

## SRP-PHAT (Steered Response Power - PHAT)

각 후보 방향에 빔을 조향하여 응답 전력이 최대인 방향을 음원 방향으로 결정.

```python
import numpy as np
from scipy.fft import fft

def srp_phat(multichannel: np.ndarray,
             mic_positions: np.ndarray,
             sr: int = 16000,
             c: float = 343.0,
             n_angles: int = 360) -> tuple[float, np.ndarray]:
    """
    SRP-PHAT 방위각 추정.

    Returns:
        best_angle: 추정 방위각 (도)
        power_map:  각도별 빔 응답 전력
    """
    n_mics, N = multichannel.shape
    # 주파수 도메인 변환
    SPECS = fft(multichannel, axis=1)
    freqs = np.fft.rfftfreq(N, d=1/sr)
    SPECS = SPECS[:, :len(freqs)]

    candidate_angles = np.linspace(0, 2 * np.pi, n_angles, endpoint=False)
    power_map = np.zeros(n_angles)

    for idx, theta in enumerate(candidate_angles):
        # 조향 벡터 계산 (원거리 평면파)
        direction = np.array([np.cos(theta), np.sin(theta)])
        delays = mic_positions @ direction / c  # (n_mics,)

        # 위상 시프트 적용 후 합산
        steered = np.zeros(len(freqs), dtype=complex)
        for m in range(n_mics):
            phase_shift = np.exp(-1j * 2 * np.pi * freqs * delays[m])
            mag = np.abs(SPECS[m]) + 1e-8
            steered += SPECS[m] / mag * phase_shift

        power_map[idx] = np.sum(np.abs(steered) ** 2)

    best_angle = np.degrees(candidate_angles[np.argmax(power_map)])
    return best_angle, power_map
```

## ReSpeaker 하드웨어 빔포밍 활용

ReSpeaker USB Mic Array v2.1은 내장 DSP에서 빔포밍을 처리하고 단일 채널 출력을 제공한다. 하드웨어 DoA는 HID 인터페이스로 직접 읽을 수 있다.

```python
from tuning import Tuning
import usb.core

dev = usb.core.find(idVendor=0x2886, idProduct=0x0018)
mic = Tuning(dev)

# 하드웨어 DoA 읽기 (0~359도)
doa = mic.direction

# 음성 감지 여부
vad_status = mic.is_voice()
```

하드웨어 DoA를 **1차 추정값**으로 사용하고, 소프트웨어 GCC-PHAT/SRP-PHAT을 **보정값**으로 활용하는 하이브리드 방식이 효율적이다.

## 칼만 필터를 통한 DoA 추적

음원이 이동하는 차량이므로 단순 순간 추정이 아닌 **추적(tracking)**이 필요하다.

```python
class DoAKalmanTracker:
    def __init__(self, process_noise=5.0, measurement_noise=10.0):
        self.angle = None
        self.P = 100.0       # 초기 불확실성
        self.Q = process_noise      # 프로세스 노이즈
        self.R = measurement_noise  # 측정 노이즈

    def update(self, measured_angle: float) -> float:
        if self.angle is None:
            self.angle = measured_angle
            return self.angle

        # 예측 단계
        self.P += self.Q

        # 업데이트 단계
        K = self.P / (self.P + self.R)
        # 각도 차이 (원형 보정)
        diff = (measured_angle - self.angle + 180) % 360 - 180
        self.angle = (self.angle + K * diff) % 360
        self.P = (1 - K) * self.P
        return self.angle
```
