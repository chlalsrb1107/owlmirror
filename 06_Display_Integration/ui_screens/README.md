# UI 화면 이미지 (문서 삽입용)

문서에 넣을 화면 캡처를 모아둔 폴더. **렌더 예시**와 **실측 캡처** 두 종류가 있고,
성격이 다르니 문서에서도 구분해 쓸 것.

## 1. `render_day/` — 렌더 예시 (주간·흰 배경, 기본 테마)

`bev_render.py`의 셀프테스트로 뽑은 1600×900 PNG. 실제 화면 코드를 그대로 돌린 결과라
레이아웃·색·문구가 실물과 같다. 다만 **카메라 영역은 회색 "CAMERA" 자리표시자**이고
LiDAR 점군·감지 대상은 가짜 데이터다 — 알림 상태별 화면을 보여주는 용도.

| 파일 | 상태 |
|---|---|
| `bev_01_idle.png` | 평상시(감지 없음) |
| `bev_02_horn_once.png` | 경적 1회 — 주의 |
| `bev_03_horn_repeat.png` | 경적 반복 2회 — 경고 |
| `bev_04_siren_unmatched.png` | 사이렌, 위치 미확정(부채꼴만) |
| `bev_05_siren_confirmed.png` | 사이렌, LiDAR 매칭 확정 32m |
| `bev_06_moto_unknown.png` | 오토바이 — 사각지대 주의 |
| `bev_07_moto_loud.png` | 오토바이 근접 — 경고 |
| `bev_08_moto_tracked.png` | 오토바이 위치 추적 18m |
| `bev_09_multi.png` | 동시 감지 2건(사이렌+오토바이) |
| `bev_10_lidar_down.png` | LiDAR 미연결 폴백 — 방향만 표시 |
| `bev_11_siren_approach.png` | **최종 경로** — 카메라 지목 + 라이다 24m · 접근 ↓7m/s |
| `bev_12_moto_receding.png` | **최종 경로** — 오토바이 16m · 멀어짐 ↑5m/s |
| `bev_13_detected_no_distance.png` | 카메라는 지목했는데 거리가 아직 — "거리 확인 중" |
| `bev_14_detected_blind.png` | 지목한 오토바이가 6m 안 — 거리 대신 **사각지대** |

⚠️ **11~14번이 이 프로젝트의 최종 형태다** (2026-10-15 파이프라인 연결 이후 추가).
소리 방향이 아니라 **라이다 실측 방위**에 점·거리 라벨이 붙고, 거리 아래 접근/멀어짐
속도가 나오며, 근거가 "카메라 지목 · 라이다"로 표시된다. 문서에 한 장만 넣어야 한다면
12번을 쓸 것 — 소리→카메라 지목→라이다 거리→화면이 한 화면에 다 보인다.

11번과 12번에서는 소리 방향과 라이다 실측 방위를 일부러 6°/3° 어긋나게 넣었다.
**점 클러스터와 거리 라벨이 라이다 방위 쪽에 붙어야 맞다** — 눈으로 확인할 지점이다.

`render_night/` 는 같은 시나리오의 야간 테마(`--theme night`) 버전. 기본값은 주간이므로
문서에는 `render_day/` 를 쓰고, 테마 비교가 필요할 때만 야간을 곁들일 것.

> **2026-10-29 전부 다시 뽑았다.** 이전 이미지는 2026-09-04 것이라 10/15 파이프라인 개편
> (라이다 실측 방위·접근 속도·근거 표시) 이전 화면이었고 10장뿐이었다. 지금 것은 제출 시점
> 코드 그대로다.

### 다시 뽑는 법

```bash
cd 08_Video_Demo/code
python3 bev_render.py --selftest --outdir <출력폴더>          # 주간(기본)
python3 -c "import bev_render; from pathlib import Path; \
  bev_render.set_theme('night'); bev_render.run_selftest(Path('<출력폴더>'))"   # 야간
```

## 2. `capture_2026-09-02/` — 실측 캡처 (9/2 통합 테스트)

9/2 통합 테스트 화면 녹화(`Screencasts/…17시 38분 46초.webm` — 원본 녹화는 용량 때문에

실험실 벽·책상 리턴이다.

| 파일 | 내용 |
|---|---|
| `01_idle_rear_lidar27k.png` | 감지 없음 · 후방 카메라 · LiDAR 27,200 pts |

⚠️ **한계**: 이 녹화에는 감지가 걸린 순간이 없다. 젯슨 오디오 링크가 끊긴 구간이라
배너가 "젯슨 연결 끊김 — 오디오 감지 없음"으로 고정돼 있다. 전체 녹화 7개를 알림 색
(경고 빨강 / 주의 호박 / 오토바이 보라)으로 훑어봤지만 **감지 배너가 뜬 프레임은 없었다** —
나머지 6개는 젯슨 로그 터미널만 찍힌 노트북 화면 녹화다.

→ 경고·주의 배너가 실제로 뜬 화면이 문서에 필요하면 **다시 촬영해야 한다.**
차량 장착 촬영 때 외장 디스플레이를 화면 녹화에 포함시킬 것.
