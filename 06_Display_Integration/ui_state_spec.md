## 2. 소리 우선순위

여러 소리가 동시에 들어올 때의 처리 원칙은 **지도는 전부, 알림은 하나**입니다.
BEV 지도에는 감지된 모든 대상을 표시하고, 상단 알림 문구와 테두리 빛은 최우선 대상 하나만 반영합니다.

| 순위 | 대상 | 근거 |
|---|---|---|
| 1 | 오토바이 · 사각지대 진입 | 물리적 충돌이 가장 임박 |
| 2 | 오토바이 · 15m 이내 근접 | 급격한 진로 변경 가능성 |
| 3 | 사이렌 · 차량 확정 | 응급차량 양보 의무(법적 우선순위) — 차량까지 특정됨 |
| 4 | 사이렌 · 위치 미확정 | 양보 의무는 동일하나 대응 여유가 있음 |
| 5 | 경적 | 나를 향한 신호일 가능성이 있으나, 양보 의무가 있는 사이렌보다는 후순위 |
| 6 | 오토바이 · 15~25m 접근 | 관찰 단계 |
| 7 | 오토바이 · 멀어짐 | 알림 없음 |

동순위가 겹치면 거리가 가까운 쪽을 우선합니다. 거리를 모르는 대상끼리 겹치면 먼저 감지된 쪽을 유지합니다.

> **(2026-08-26 변경)** 기존에는 경적을 "나에게 닥친 충돌 위험" 기준으로 3위(사이렌보다 위)에 뒀으나,
> "응급차량에는 양보 의무가 있다"는 기준으로 재논의해 **사이렌을 경적보다 항상 위**로 정정함
> (오토바이 근접/사각지대 두 단계는 물리적 충돌 위험 기준이라 순서 변경 없음). 9/8 데모 코드
> (`08_Video_Demo/code/live_demo.py`)의 `PRIORITY = {"siren": 1, "car_horn": 2, "motorcycle": 3}`도
> 이 기준으로 맞춰져 있음.

### 동시 감지 시 화면 표현 (9/8 데모)

BEV 지도가 없는 9/8 데모에서는 "지도는 전부, 알림은 하나" 원칙을 다음과 같이 구현한다.
클래스별 감지를 각자의 hold 시각과 함께 계속 들고 있다가, 화면을 그릴 때 우선순위 1위만
메인 카메라 전환 + 배너로 쓰고, 나머지는 버리지 않고 화면 우측 상단에 작은 색 아이콘 +
방향 라벨(예: "경적 · 좌측")로 함께 표시한다. 메인 자리를 차지한 대상의 hold가 끝나면
남아있던 차순위 대상이 자동으로 메인 자리로 승격된다.

## 3. 상태 진입 및 해제

소리는 순간적으로 끊겼다 이어지므로, 감지 결과를 그대로 화면에 연결하면 알림이 깜빡입니다.
진입과 해제 조건을 다르게 두어 이를 막습니다.

| 구분 | 조건 |
|---|---|
| 진입 | 신뢰도 0.6 이상이 **2프레임(약 0.5초) 연속** |
| 유지 | 마지막 감지 시점으로부터 **3초** |
| 해제 | 유지 시간 경과 후 0.5초에 걸쳐 사라짐 |
| 단계 하향 | 조건이 낮아져도 **1초 유지 후** 전환 |
| 단계 상향 | 조건 충족 즉시 전환 |

단계 상향은 즉시, 하향은 지연시키는 것이 원칙입니다. 위험은 빨리 알리고 늦게 거둡니다.

## 4. 위치 확정 여부에 따른 전환

| 전환 | 조건 | 표현 |
|---|---|---|
| 부채꼴 → 마커 | 카메라가 대상을 식별하고 LiDAR 거리가 연결됨 | 0.4초에 걸쳐 부채꼴이 좁아지며 마커로 수렴 |
| 마커 → 부채꼴 | 대상 추적을 놓침 | 마커를 1초 유지한 뒤 부채꼴로 복귀 |
| 마커 → 구역 점등 | 대상이 반경 6m 안으로 진입 | 마커를 지우고 해당 방향 구역만 점등 |

위치가 확정되기 전에는 어떤 경우에도 특정 차량에 마커를 찍지 않습니다.
잘못된 지목은 알려주지 않는 것보다 위험합니다.

## 6. 깜빡임 주기

경고 단계 마커는 거리에 반비례하는 주기로 깜빡입니다.

```
T = 0.3 + 0.05 × R   (초, R은 미터)
최소 0.3초 · 최대 1.2초
사각지대 진입 시 0.3초 고정
```

시스템 설정에서 동작 줄이기가 켜져 있으면 깜빡임 대신 고정 표시로 대체합니다.

## 7. 장치 간 인터페이스

Jetson은 오디오만 처리하고, 아래 한 줄을 초당 4회 노트북으로 보냅니다.
영상과 점군은 오가지 않습니다.

```json
{
  "t": 1751250042.318,
  "class": "siren",
  "conf": 0.91,
  "theta": 194.0,
  "sigma": 12.0
}
```

| 필드 | 설명 |
|---|---|
| `t` | 분석 구간의 **중심 시각** (구간 시작 시각이 아님) |
| `class` | `siren` · `horn` · `motorcycle` · `none` |
| `conf` | 0.0 ~ 1.0 |
| `theta` | 차량 좌표계 방위각 (전방 0°, 반시계 +) |
| `sigma` | 방향 오차 표준편차 (도) — 부채꼴 폭 계산에 사용 |

부채꼴 폭은 `2 × sigma`로 그립니다. 오차가 클수록 넓게 표시되어 불확실성이 그대로 드러납니다.

### 시각 기준 원칙

주행 중에는 50 km/h 기준으로 100 ms에 약 1.4 m를 이동합니다.
LiDAR는 한 바퀴에 100 ms가 걸리므로, 같은 프레임 안에서도 정후방과 우측에서 관측된 점 사이에는 최대 100 ms의 시각 차이가 있습니다.

따라서 **프레임 시각이 아니라 점별 시각을 사용합니다.**
검출된 물체에는 그 물체의 방위각에서 유도한 시각을 붙이고, 오디오와 맞출 때 이 값을 기준으로 합니다.

물체 하나가 일그러지는 정도는 무시할 수 있습니다. 30 m 뒤 차량은 방위각 약 20°를 차지하므로 훑는 시간은 5.6 ms이고, 그동안 자차는 7.7 cm만 움직입니다.

## 8. 남은 결정 사항

| 항목 | 현재 안 | 검토 필요 |
|---|---|---|
| 경적의 단계 | 주의 | 나를 향한 경적이면 경고로 올릴지 |
