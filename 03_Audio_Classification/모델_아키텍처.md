## 추천 아키텍처: MobileNet-V3 Small 기반 CNN

```python
import torch
import torch.nn as nn
from torchvision.models import mobilenet_v3_small

class SoundClassifier(nn.Module):
    def __init__(self, num_classes=4):
        super().__init__()
        backbone = mobilenet_v3_small(pretrained=False)
        # 1채널 입력으로 변경 (Mel-Spectrogram)
        backbone.features[0][0] = nn.Conv2d(
            1, 16, kernel_size=3, stride=2, padding=1, bias=False
        )
        # 분류 헤드 교체
        backbone.classifier[-1] = nn.Linear(1024, num_classes)
        self.model = backbone

    def forward(self, x):
        return self.model(x)

# 모델 파라미터 수 확인
model = SoundClassifier()
params = sum(p.numel() for p in model.parameters())
print(f"Parameters: {params:,}")  # ~1.5M
```

## 클래스별 임계값 설정

배경 소음 오탐을 줄이기 위해 클래스별 신뢰도 임계값을 다르게 설정한다.

| 클래스 | 임계값 | 이유 |
|---|---|---|
| car_horn | 0.70 | 오탐보다 미탐이 더 위험 |
| emergency_siren | 0.65 | 긴급 상황 → 낮은 임계값 |
| motorcycle_exhaust | 0.75 | 배기음 유사 소음 많음 |
| background | - | 나머지 클래스 모두 미만 시 |
