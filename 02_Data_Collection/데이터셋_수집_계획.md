> **한국 사이렌 특이사항**: 한국 구급차/경찰차/소방차는 대부분 YELP 방식(톤/주파수만 차이)이고 일부 HI-LO("삐뽀삐뽀")도 사용. 해외 데이터셋(sireNNet 등)은 미국식 wail/yelp/phaser 패턴이라 주파수 특성이 다를 수 있음 → **학습은 AI Hub 위주, 해외 데이터셋은 augmentation 용도로만.**

### 오토바이 배기음 (`motorcycle_exhaust`) — 전용 공개 데이터셋 없음

조사 결과 배기음 특화 공개 데이터셋이 없어 **직접 수집이 사실상 필수**:

1. **직접 녹음**: 스쿠터/중형/대형 바이크별 공회전·가속·통과(pass-by) 시나리오 각각 녹음. ReSpeaker로 직접 캡처하면 실제 배포 환경(마이크 위치, 도로 반사음)과 가장 닮아있어 소량이라도 fine-tuning 효과가 큼
2. **Freesound.org**: "motorcycle exhaust", "motorbike pass by" 검색 후 CC0/CC-BY 라이선스만 필터링
3. **Kaggle "Vehicle Sounds Dataset"**: 배기음 특화는 아니지만 근접 클래스로 보조 활용 가능
4. YouTube 배기음 리뷰 영상 오디오 추출은 저작권 이슈 있으니 비상업 연구 목적 한정, 출처 명시 권장

## 직접 수집 방법

```bash
# 현장 녹음 스크립트 (ReSpeaker v3.0, 4ch)
python3 record_multichannel.py \
    --duration 3 \
    --samplerate 16000 \
    --channels 4 \
    --output ./raw_recordings/car_horn/
```

### 수집 환경 권장 사항

- 다양한 차종의 경적 (승용차, SUV, 트럭)
- 다양한 거리 (5m, 10m, 20m, 50m)
- 다양한 도로 환경 (도심, 고속도로, 주차장)
- 다양한 날씨 (맑음, 흐림, 빗속)

## 데이터 증강 (Augmentation)

```python
import librosa
import numpy as np

def augment_audio(y, sr):
    augmented = []

    # 1. 시간 이동
    shift = np.random.randint(0, sr // 2)
    augmented.append(np.roll(y, shift))

    # 2. 피치 변환 (+/- 2 반음)
    for steps in [-2, -1, 1, 2]:
        augmented.append(librosa.effects.pitch_shift(y, sr=sr, n_steps=steps))

    # 3. 배경 소음 추가 (SNR 5~20dB)
    noise = np.random.randn(len(y)) * 0.005
    augmented.append(y + noise)

    # 4. 시간 스트레칭 (0.8x ~ 1.2x)
    for rate in [0.8, 0.9, 1.1, 1.2]:
        augmented.append(librosa.effects.time_stretch(y, rate=rate))

    return augmented
```
