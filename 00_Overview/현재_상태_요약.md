## 확정 하드웨어

- Jetson Orin Nano Super Developer Kit (8GB)
- ReSpeaker Mic Array v3.0 (XMOS XVF-3800, **4채널**, USB-C) — `01_Hardware/ReSpeaker_설정.md` 참고
- **Depth 카메라: Orbbec Gemini 215 확정 구매/보유중**
  - RGB FOV: 74.7°×46.2° / Depth FOV: 63.5°×45.6°
  - ⚠️ **뎁스 유효 측정거리 0.15~0.70m뿐** — 근접 3D스캔용 카메라라 도로 위 차량(수 m~수십 m) 거리 측정이 물리적으로 불가능
  - → 거리는 Depth 스트림이 아니라 **RGB 스트림의 YOLO 바운딩박스 폭 기반 단안(monocular) 거리 추정**으로 대체
    - `거리(m) = (실제 폭 × focal_px) / bbox 폭_px`, `focal_px = (이미지가로해상도/2) / tan(수평FOV/2)`
    - 차량 평균폭 ≈1.8m, 오토바이 ≈0.8m 기준값 사용
  - Depth 스트림은 70cm 이내 초근접 경고 등 부가 기능으로만 활용
- 차량용 디스플레이: 미구매

## 음향 분류 모델 현재 상태

- UrbanSound8K 전체 클래스로 Transformer 학습 완료, **정확도 90%대 확보**
- ⚠️ UrbanSound8K에는 `motorcycle_exhaust` 클래스가 없음 → 이 모델은 "분류 파이프라인이 정상 작동함을 검증"한 것이지 최종 타겟(4클래스) 모델이 아님
- 실제 타겟 4클래스(car_horn / emergency_siren / motorcycle_exhaust / background) 모델은 별도 재학습 필요:
  - AI Hub "도시 소리 데이터" (한국 경적 4,001건 / 사이렌 2,508건, 신청 승인 필요, 내국인만)
  - sireNNet 등 해외 사이렌 데이터셋은 보조/augmentation 용도로만 (한국 사이렌은 YELP/HI-LO 패턴이라 해외 wail/phaser 패턴과 주파수 특성 다름)
  - 오토바이 배기음은 전용 공개 데이터셋 없음 → 직접 녹음 필수 (`02_Data_Collection/데이터셋_수집_계획.md` 참고)

## 위치추정 (방향, 거리 아님)

- ReSpeaker 하드웨어 DoA(`AEC_AZIMUTH_VALUES`, v3.0 host_control 명령) + GCC-PHAT 자체 구현을 교차검증
- 빔포밍(SRP-PHAT)은 방향 정밀화용
- **TDoA/빔포밍은 방향(각도)만 제공, 거리는 원천적으로 못 구함** — 마이크 어레이 반경(4.3cm)이 음원 거리에 비해 너무 작아 평면파 가정을 쓰기 때문. 거리는 카메라(RGB 단안거리)가 전담.

## 카메라 트래킹 설계

- 고정 카메라 + FOV 내 ROI 방식 채택 (PTZ 모터 방식은 9일 안에는 리스크가 커서 보류, 본평가 로드맵으로만 언급)
- DoA 각도가 카메라 FOV(약 ±32° = 63.5°/2) 밖이면 영상 없이 **방향 텍스트 알림만** 표시
- 동일 방향에 후보 차량이 여럿일 때 우선순위 스코어:
  `점수 = 클래스가중치(사이렌=3, 배기음=2, 경적=1) × (1/추정거리) × confidence`
  → 최고점 차량만 강조 표시, 나머지는 보조 표시

## 차별화 방향 (중요 — 작년 임베디드SW 경진대회 대상작과 겹치면 안 됨)

- 작년 대상작이 이미 커버한 영역: 룸미러 방향 텍스트/화살표 표시, 시트·핸들 진동 피드백
- 우리 차별점으로 확정한 방향:
  1. **예측형 위험도 판단**: DoA 각도 변화(칼만필터) + bbox 크기 변화(접근속도)로 "몇 초 후 경로 교차 예상" 등 지능형 판단 결과를 출력 (단순 방향 알림이 아니라 판단/추론 결과)
  2. **차량 개조 불필요한 폰/워치 컴패니언 알림**: Jetson이 판단한 결과를 BLE로 스마트폰/워치에 전송, 진동+표시. 특정 차량에 종속되지 않는 범용성이 장점
  - 카메라 영상은 판단 근거를 확인하는 보조 화면으로 유지 (기존 작업 그대로 재사용)
