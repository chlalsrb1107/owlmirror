## 전제 (변경사항)

- 카메라: 정식 4대 중 **3대만 확보 — 좌/우/후방으로 확정** (전방 제외). **후방 카메라를 기본 화면으로 상시 표시**하다가 좌/우 방향에서 소리가 감지되면 그쪽 카메라로 전환, 전방(북) 방향이면 카메라 전환 대신 "전방 확인" UI 텍스트로 대체
- 카메라 기종: **Daheng Imaging MER2-240-159U3C**(2.4MP USB3 Vision 산업용 area-scan 카메라) + C-mount 2.8mm 렌즈(고정초점, 광각) — 일반 UVC 웹캠이 아니라 벤더 SDK(`gxipy`)로 접근해야 함, USB3.0 케이블로 노트북과 유선 연결 필요. 상세: `08_Video_Demo/code/live_demo.py`
- LiDAR: 없음 → **(2026-08-25 결정) BEV 지도 자체를 이번 데모에서 뺌.** 카메라 영상이 주화면, 방향 정보는 상단 알림 배너로만 전달, 모든 감지는 "주의" 단계까지만(거리 모르는 채로 "경고"는 안 씀). 상세: `08_Video_Demo/README.md` "화면 UI" 절, 목업 `08_Video_Demo/camera_ui_mockup.html`
- 실차: 사용 가능하나 미부착 상태 — **팀이 촬영 당일 직접 임시 부착**해야 함
- 구급차·오토바이 시각 Detection: 팀원이 학습한 YOLO 모델 연동 완료 (`08_Video_Demo/model_outputs/yolo26m_v4_cls05/`, val mAP50 0.919)

## 영상 구성과의 매핑

(이전 논의한 90초 구성 기준)

| 세그먼트 | 필요한 촬영 소스 | 비고 |
|---|---|---|
| ① 오토바이 사각지대/골목 경고 | 오토바이 실제 통과 or 배기음 재생 + 골목/모퉁이 환경 | 라이다·카메라 불필요, 오디오만으로 완결 — **가장 먼저 확보할 샷** |
| ② 사이렌 감지 → 방향추정 → 카메라 자동 전환(PIP) | 스피커 탑재 차량과 동시 주행 (기존 방식 재사용) | 기본은 후방 카메라, 스피커차량이 좌/우에서 접근하며 전환되는 장면으로 구성. 정면 접근 시나리오는 "전방 확인" 텍스트로 대체(카메라 없음) |
| ③ 카메라 주화면 + 상단 알림 배너 | 노트북 화면 녹화 (OBS 등), ①②와 시간 동기화 | **(2026-08-25 변경) BEV 지도는 이번 데모에서 제외** — 카메라 영상이 주화면, 방향은 알림 배너로만. 목업: `08_Video_Demo/camera_ui_mockup.html` |
| ④ (여유 시) 경광등 점멸 검출 | 정지 상태에서 점멸광 재현 or 실제 긴급차량 촬영 | 카메라만으로 가능한 M4 보너스 |
