# ReSpeaker 기반 차량 위험음 감지 및 추적 시스템

## 프로젝트 목적

주행 중 운전자가 놓치기 쉬운 **자동차 경적 / 긴급차량 사이렌 / 오토바이 배기음**을 실시간으로 감지하고, 해당 음원의 방향을 추적하여 카메라 영상을 운전자에게 제공함으로써 **교통 안전성**을 높인다.

---

## 핵심 구성 요소

| 구성 요소 | 모델 | 역할 |
|---|---|---|
| ReSpeaker Mic Array v3.0 | XMOS XVF-3800, 4-Mic | 다채널 오디오 입력, 하드웨어 TDoA/빔포밍 |
| Jetson Orin Nano Super | Developer Kit, 8GB | AI 추론 (음원 분류 + 방향 추정) |
| Depth 카메라 | Intel RealSense D435/D455 등 | 차량 탐지(YOLO) + 거리 측정 + 방향 확인 |
| 차량 내부 디스플레이 | 구매 예정 | 운전자에게 영상 및 경보 출력 |

> **센서 퓨전 전략**: 오디오(무엇이/어느 방향) + Depth 카메라(실물 확인/거리)는 상호 보완적이며, ADAS의 표준 다중 센서 퓨전 구조다.

---

## 전체 파이프라인 요약

```
[ReSpeaker Mic Array v3.0]
        │  4ch PCM 오디오 스트림
        ▼
[전처리 모듈] ──── Mel-Spectrogram 변환
        │
        ├──▶ [음원 분류 모델 (TensorRT on Jetson)]
        │         └─ 경적 / 사이렌 / 배기음 / 배경 분류
        │                   │ 이벤트 트리거
        └──▶ [음원 위치 추정]──┘
                  ├─ 하드웨어 DoA (XVF-3800 내장)
                  └─ GCC-PHAT 소프트웨어 보정
                            │ 방위각 θ
                            ▼
              ┌─────────────────────────────┐
              │  [센서 퓨전 판단 모듈]        │
              │  오디오 DoA → 카메라 시야 유도 │
              └─────────────┬───────────────┘
                            │
        [Depth 카메라]───────┘
         RGB + Depth 스트림
         │
         ├─ YOLOv8 차량 탐지 (car/motorcycle/bus)
         └─ Depth → 거리 + 접근 속도 추정
                            │
                            ▼
                   [위험도 레벨 산출]
                   (거리 × 속도 × 위협 유형)
                            │
                            ▼
                   [디스플레이 출력]
                   (영상 + HUD 경보)
```

## 기대 성능 목표

- 음원 분류 정확도: **≥ 90%** (테스트셋 기준)
- DoA 추정 오차: **≤ 10°**
- 엔드투엔드 지연 (오디오 입력 → 화면 출력): **≤ 300ms**
- Jetson Orin Nano 추론: **실시간 (30fps 이상)**
