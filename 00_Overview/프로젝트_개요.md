# 올빼미러 — AI 기반 실시간 외부 음향 인식 및 운전자 시각화 보조 시스템

> ⚠️ 이 문서는 개요용 요약이며, 세부 수치·최신 결정 사항은 `00_Overview/현재_상태_요약.md`가 항상 우선한다.

## 프로젝트 목적

주행 중 운전자가 놓치기 쉬운 **자동차 경적 / 긴급차량 사이렌 / 오토바이 배기음**을 실시간으로 감지하고, 소리의 방향과 (LiDAR로 측정한) 거리를 계산해 BEV(Bird's-Eye View) 지도로 운전자에게 보여줌으로써 **교통 안전성**을 높인다.

작년 임베디드SW 경진대회 대상작(룸미러 방향 텍스트/화살표, 시트·핸들 진동 피드백)과 겹치지 않도록, **오토바이 사각지대·골목 경고**(카메라·LiDAR가 보지 못하는 벽 뒤/근접 구간을 소리로 먼저 감지)와 **위험도 단계 기반 BEV UI**를 핵심 차별점으로 삼는다.

## 핵심 구성 요소

| 구성 요소 | 모델 | 담당 기기 | 역할 |
|---|---|---|---|
| ReSpeaker Mic Array | v2.0, 6채널 (ch0 AEC / ch1~4 raw / ch5 재생 참조) | Jetson | 다채널 오디오 입력 |
| Jetson Orin Nano Super | Developer Kit, 8GB | Jetson | 소리 분류(AST) + 방향(DoA) 추정 — **오디오 전담** |
| 카메라 | 일반 카메라 4대, 차량 전/후/좌/우 90° 간격 | 노트북 | 영상 확인 + 경광등 점멸 검출 |
| LiDAR | Velodyne VLP-16, 루프랙 프레임 중앙 최상단 | 노트북 | 후보 차량까지의 거리 측정 (±2%) |
| 노트북 | ASUS TUF A16, Ubuntu, ROS2 | 노트북 | 카메라/LiDAR 처리, 방향-거리 매칭, BEV UI 표시 |

> **센서 역할 분리**: 카메라는 "사람이 보는 장면", LiDAR는 "거리", 오디오는 "무엇이 어느 방향에" — 세 센서를 매칭해 하나의 대상을 특정한다.

## 시스템 아키텍처 — Jetson/노트북 분리

Jetson 한 대가 오디오·영상·거리·화면을 모두 처리하는 구조는 폐기되었고, **Jetson은 오디오만 전담**, 나머지(영상 확인·거리 계산·화면 표시)는 노트북이 처리한다.

```
[Jetson] 오디오 전담
  - ReSpeaker 4채널 수음
  - 소리 종류 분류 (AST, 5클래스: car_horn/children_playing/engine_idling/siren/motorcycle)
  - 소리 방향 추정 (ReSpeaker 하드웨어 DoA + GCC-PHAT 자체 구현, 오차 ±10~20°)
  → JSON 한 줄만 노트북으로 전송 (영상·점군은 오가지 않음), ROS 미사용

[노트북] 영상·거리·화면 (ROS2)
  - 소리 방향에 해당하는 카메라 영상 확인 (경적/사이렌 시 PIP 자동 표시)
  - 경광등 점멸 검출 (YOLO 기반, 평상시 경로)
  - LiDAR로 후보 차량들의 거리 측정 → 소리 방향과 맞는 차량 특정 (거리는 소리/카메라가 아니라 LiDAR가 직접 측정)
  - BEV 지도 + 상태 기반 알림(IDLE/표시/주의/경고)으로 화면 표시
```

두 기기는 **이더넷 케이블로 직결**하며, 상세 통신 설계(브릿지 노드, 토픽 구조, 시계 동기화 등)는 `00_Overview/현재_상태_요약.md`의 "통신 미들웨어 및 물리 연결" 절과 `07_System_Integration/전체_시스템_통합.md` 참고.

## 현재까지 달성한 성능 (2026-08-17 기준)

- 음원 분류 정확도: 검증셋 **91.0%** (UrbanSound8K 10클래스 파이프라인 검증용 모델 기준)
- **실차 검증**: 시속 50km/h 주행 중 인식 정확도 **70%**, 수음 범위 360°
- DoA 추정 오차: **±10~20°**
- 거리 정확도: LiDAR 기준 **±2%** (반경 6m 이내는 물리적 사각지대)
- 엔드투엔드 지연: **아직 미측정** — Jetson이 GPU 미인식으로 CPU 추론 중(TensorRT 미적용), 실시간 인터페이스 주기도 스펙(초당 4회)과 실제 코드 기본값(2초당 1회)이 어긋나 있어 정리 필요 (`현재_상태_요약.md` 참고)
