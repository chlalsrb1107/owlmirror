## 중간평가에 포함할 핵심 결과물

### 1. 정량적 지표 (반드시 포함)
- 클래스별 Precision / Recall / F1
- Confusion Matrix
- Jetson 추론 시간 (ms)
- 모델 크기 (MB, TRT 변환 후)

### 2. 시연 시나리오
```
① 경적 소리 재생 → ReSpeaker 입력 → Jetson 추론 → "car_horn 감지" 출력
② 사이렌 소리 재생 → "emergency_siren 감지" 출력
③ 배경 소음 → "background" 출력 (오탐 없음 확인)
```

### 3. 향후 계획 슬라이드 (평가자에게 완성형 그림 제시)
- 센서 퓨전 아키텍처 다이어그램 (오디오 + Depth 카메라)
- UI 목업 (경보 화면, 방향 표시, 거리 정보)
- 최종 시스템 통합 로드맵

### 클래스 구성 권장안 (중간평가 버전)

| 클래스 | 데이터 소스 | 샘플 수 목표 |
|---|---|---|
| car_horn | UrbanSound8K (class_id=1) | ~400개 |

## 주의사항

- 모델 학습은 **Jetson에서 하지 말 것** — 시간이 수십 배 더 걸린다. PC 또는 Colab에서 학습 후 `.pth` → `.onnx` → `.engine` 순으로 변환.
- TensorRT 변환은 **Jetson에서 직접** 실행해야 한다 (PC에서 만든 .engine은 호환 안 됨).
- 중간평가에서 DoA/빔포밍이 불완전해도 괜찮다. 음원 분류가 완성된 것이 핵심.
