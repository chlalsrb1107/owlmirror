## 중간평가~중간보고 사이 실제 달성 내용

당초 계획했던 MobileNet-V3 / 목표 정확도 85% 기준은 실제로는 아래와 같이 상향 달성되었다:

- 음원 분류: **Transformer(AST)** 기반으로 학습, UrbanSound8K 10클래스 검증 정확도 **91.0%**
- **실차 검증까지 완료**: 시속 50km/h 주행 중 인식 정확도 70%, 수음 범위 360°
- 센서 구성이 중간보고에서 크게 바뀜: RGB 단안거리 추정 → **카메라 4대 + LiDAR VLP-16** 기반 방향-거리 매칭 방식으로 전환 (근거: `현재_상태_요약.md` "센서 구성 비교" 표)
- UI/UX: 단순 목업이 아니라 **BEV(Bird's-Eye View) 지도 + 상태 기반 알림** 설계로 구체화 (`06_Display_Integration/ui_state_spec.md`, `bev_mockup.html`)

멘토 발표에서 정리된 남은 한계 3가지(어느 차량인지 지목 불가 / 방향 오차 큼 / 거리 계산 불가)는 각각 LiDAR 매칭, 방향 추정 정밀화, LiDAR 도입으로 해결 방향이 잡혔다. 자세한 내용은 `현재_상태_요약.md` 참고.

## 이후 전략 (M1~M5)

| 단계 | 내용 | 상태 |
|---|---|---|
| M1 | 소리 인식 개선 — 방풍 커버(데드캣) 장착 후 주행 정확도 재측정 | 준비 |
| M2 | 방향 추정 — 사이렌 전용 방향 추정 적용 | 준비 |
| M3 | 카메라 전환 — 소리 방향 카메라 화면 자동 표시 | **시연 가능** |
| M4 | 경광등 검출 — YOLO 점멸 인식 + LiDAR 거리 연결 | 확장 |
| M5 | 오토바이 경고 — 배기음 데이터 수집, 골목·근접 경고 | 확장 |

**3단계(M3) 이후로는 언제든 시연 가능한 상태 유지**가 목표.

### 측정 항목 (최종 결과물에 포함할 정량 지표)

- 인식 정확도 (속도별·소리 종류별)
- 방향 오차 (실제 각도 대비)
- 지목 정확도 (정답 차량 선택률)
- 오경보 횟수 (일반 주행 10분당)

### 시험 방법

다른 차량 지붕에 스피커를 얹고 함께 주행 → 그 차량이 정답. 긴급차량은 별도 학습 데이터 불필요, **오토바이 배기음만 직접 녹음** 필요 (주행 소음 섞어 학습해야 실도로 성능 유지). 시험 범위는 차량 속도 정보를 직접 받기 어려워 **직선 정속 구간**으로 한정 예정.
