# 상세 파이프라인 다이어그램

> ⚠️ 이전 버전(Jetson 단독 6채널 15쌍 TDoA + 단일 카메라)은 폐기됨. 확정 구조는 **Jetson(오디오 전담) / 노트북(영상·거리·화면, ROS2) 분리**다. 배경: `00_Overview/현재_상태_요약.md` "시스템 아키텍처" 절.

## 레이어 구조

```
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 1 — Jetson 하드웨어 입력                                   │
│                                                                   │
│   ReSpeaker 4 Mic Array v2.0 (6채널: ch0 AEC / ch1~4 raw / ch5 재생참조) │

└─────────────────────────────────────────────────────────────────┘
                              │  6ch PCM, 16kHz
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 2 — Jetson 신호 처리 (현재 CPU만, GPU 미인식)               │

│  ┌─────────────────────┐   ┌──────────────────────────────────┐ │
│  │   음원 분류 브랜치    │   │     위치 추정 브랜치              │ │

│  │  → PANNs Cnn14 임베딩 │   │  + GCC-PHAT 자체 구현 교차검증  │ │

             └──────────────┬────────────────┘
                             ▼
              JSON 1줄 (t, class, conf, theta, sigma)
              ROS 미사용, 소켓 → 이더넷 직결 → 노트북
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐

│  ① 방향으로 카메라 선택   doa_camera_select.select_camera(theta)   │

│       → 구급차/오토바이 박스 (클래스가 어긋나면 버린다)             │
│  ③ 박스 → 방위각 환산      camera_bearing.bearing_from_box()       │
```

## 데이터 흐름 타이밍

측정 완료된 항목과 아직 미측정인 항목을 구분한다 — 이전 버전 문서의 163ms 총 지연 표는 실제 측정치가 아니라 목표 추정치였으므로 폐기.

| 단계 | 상태 | 비고 |
|---|---|---|
| Jetson CPU 추론 (오디오 3초 기준) | **측정됨: 약 3.9초** | GPU 미인식, TensorRT 미적용 — 최적화 필요 |
| Jetson→노트북 전송 주기 | **실측 1.22초** (2026-09-02) | `--interval` 기본값 2.0→0.0으로 해결. 추론은 0.2초라 병목이 아니었다 |
| GCC-PHAT DoA 계산 | 코드 구현됨(`04_Sound_Localization/code/gcc_phat.py`) | 실측 지연 미기록 |
| LiDAR 클러스터링 + YOLO 매칭 | **구현 완료(2026-10-15)** · 실차 미검증 | 책상 검증: `pipeline_selftest.py` ALL PASS |
| YOLO 추론 | 실측 46~86ms (첫 회 3.3초) | 2026-09-02 |
| BEV UI 갱신 | **구현 완료** 6~8ms/프레임 (1920×1080) | 2026-09-02 실측 |
| **엔드투엔드 지연** | **미측정** | 위 항목들이 다 붙어야 의미 있는 수치가 나옴 |

> 목표치를 미리 못박기보다, 위 표의 "미측정" 항목이 채워지는 대로 실측 기반으로 갱신할 것.
