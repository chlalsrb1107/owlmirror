# 상세 파이프라인 다이어그램

> ⚠️ 이전 버전(Jetson 단독 6채널 15쌍 TDoA + 단일 카메라)은 폐기됨. 확정 구조는 **Jetson(오디오 전담) / 노트북(영상·거리·화면, ROS2) 분리**다. 배경: `00_Overview/현재_상태_요약.md` "시스템 아키텍처" 절.

## 데이터 흐름 타이밍

측정 완료된 항목과 아직 미측정인 항목을 구분한다 — 이전 버전 문서의 163ms 총 지연 표는 실제 측정치가 아니라 목표 추정치였으므로 폐기.

| 단계 | 상태 | 비고 |
|---|---|---|
| Jetson CPU 추론 (오디오 3초 기준) | **측정됨: 약 3.9초** | GPU 미인식, TensorRT 미적용 — 최적화 필요 |
| Jetson→노트북 전송 주기 | **스펙-코드 불일치** | 인터페이스 스펙은 초당 4회(250ms), `realtime_classify.py` 기본값은 2초당 1회 — 정리 필요 |
| GCC-PHAT DoA 계산 | 코드 구현됨(`04_Sound_Localization/code/gcc_phat.py`) | 실측 지연 미기록 |
| LiDAR 클러스터링 + YOLO 매칭 | 미구현 | 세부 구현 후 측정 |
| BEV UI 갱신 | 정적 목업만 존재 | 실시간 데이터 연동 전 |
| **엔드투엔드 지연** | **미측정** | 위 항목들이 다 붙어야 의미 있는 수치가 나옴 |

> 목표치를 미리 못박기보다, 위 표의 "미측정" 항목이 채워지는 대로 실측 기반으로 갱신할 것.
