# 상세 파이프라인 다이어그램

## 레이어 구조

```
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 1 — 하드웨어 입력                                          │
│                                                                   │
│   [Mic 0] [Mic 1] [Mic 2] [Mic 3] [Mic 4] [Mic 5]              │
│        └──────────────────────────────────┘                      │
│                    ReSpeaker 6-Mic Array                          │
│              (USB / I2S → Jetson Orin Nano)                      │
└─────────────────────────────────────────────────────────────────┘
                              │
                              │  6ch PCM, 16kHz, 16bit
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 2 — 신호 처리 (Jetson CPU / DSP)                          │
│                                                                   │
│  ┌─────────────────────┐   ┌──────────────────────────────────┐ │
│  │   음원 분류 브랜치    │   │     위치 추정 브랜치              │ │
│  │                     │   │                                  │ │
│  │  믹스다운(1ch)       │   │  채널 간 GCC-PHAT 계산           │ │
│  │  → STFT             │   │  → TDoA 행렬 (15쌍)              │ │
│  │  → Mel-Spectrogram  │   │  → 음속 보정 (온도 반영)         │ │
│  │  → 정규화           │   │  → 빔포밍 (SRP-PHAT / MUSIC)    │ │
│  └─────────┬───────────┘   └───────────────┬──────────────────┘ │
└────────────┼───────────────────────────────┼───────────────────-┘
             │                               │
             ▼                               ▼
┌────────────────────────┐   ┌───────────────────────────────────┐
│  LAYER 3 — AI 추론     │   │  DoA 출력                         │
│  (Jetson GPU, TensorRT)│   │                                   │
│                        │   │  방위각 θ ∈ [0°, 360°)           │
│  경량 CNN / EfficientNet│   │  고도각 φ (선택)                  │
│  분류: 4클래스          │   │  신뢰도 점수                      │
│  - 자동차 경적          │   └──────────────┬────────────────────┘
│  - 긴급차량 사이렌      │                  │
│  - 오토바이 배기음      │                  │
│  - 배경 소음 (무시)     │                  │
└──────────┬─────────────┘                  │
           │ 이벤트 트리거                   │
           └──────────────┬─────────────────┘
                          │  (분류 결과 + DoA)
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 4 — 카메라 제어                                           │
│                                                                   │
│  DoA → PTZ 카메라 Pan/Tilt 각도 매핑                             │
│  → 서보 제어 신호 (PWM / RS-485)                                 │
│  → 카메라 줌 레벨 결정 (거리 추정 기반)                           │
└─────────────────────────────────────────────────────────────────┘
                          │
                          │  RTSP / V4L2 영상 스트림
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 5 — 영상 처리 및 출력                                      │
│                                                                   │
│  GStreamer 파이프라인                                             │
│  → YOLOv8n 객체 감지 오버레이 (선택)                             │
│  → 분류 결과 + 방향 HUD 오버레이                                  │
│  → HDMI 출력 / CAN-bus 연동 차량 디스플레이                      │
└─────────────────────────────────────────────────────────────────┘
```

## 데이터 흐름 타이밍

| 단계 | 예상 지연 |
|---|---|
| 오디오 버퍼 수집 (512 샘플 @ 16kHz) | ~32ms |
| GCC-PHAT TDoA 계산 | ~5ms |
| Mel-Spectrogram 변환 | ~3ms |
| TensorRT 추론 (분류) | ~10ms |
| 빔포밍 DoA 계산 | ~8ms |
| 카메라 Pan/Tilt 명령 전송 | ~5ms |
| 영상 캡처 → 디스플레이 렌더링 | ~100ms |
| **총 지연** | **~163ms** |

> 목표 300ms 이내 충분히 달성 가능한 수준.
